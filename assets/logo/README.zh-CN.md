## README 腰像

[logo-waist.png](logo-waist.png) 是从 [原始 logo.png](logo.png) 直接裁出的 **768 × 784 RGBA** 腰像。README 中按 **420 CSS 像素宽**展示，窄屏自动缩小，让脸部、发饰、手部与腰带细节更清晰；点击可打开完整原图。

裁切框基于 1024 × 1536 原图：**左 96、上 0、右 864、下 784**，右／下边界不包含在内。只裁切像素，不缩放、不改色、不重绘、不修补透明通道。原图与所有已有 PNG 尺寸变体保持不变。

安装 Python 与 Pillow 后可复现：

```sh
python assets/logo/crop_logo.py
```

[裁切脚本](crop_logo.py) 检查源图尺寸与模式、输出尺寸、像素一致性和原图哈希；发现已有输出不同会拒绝覆盖，需通过 `--output <新文件.png>` 保存待验收版本。这只是可选的素材维护工具，不是插件运行依赖。
